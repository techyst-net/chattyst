# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to **support@techyst.net**.
Please do not open a public issue for security reports.

Include where possible: affected version or commit, the impact, and steps to
reproduce.

## Upstream advisories

This product is derived from a third-party customer-support platform whose core
is MIT-licensed (see `UPSTREAM.md`). Security advisories published for that
upstream project apply here. Track upstream releases and apply relevant patches.
